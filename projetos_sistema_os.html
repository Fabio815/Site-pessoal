Tecnologias e conceitos usados

Nesta aplicação foram usados as seguintes aplicações e conceitos:

  • Java com SpringBoot - backend
  • Ext.js - front end
  • Mysql
  • Conceito de DDD (Domain Driven Design)
  • Git

No início do projeto, o desenvolvimento foi feito utilizando apenas Java, sem o apoio de frameworks.

Utilizei Servlets/JAX-RS para criação das APIs, JDBC para acesso ao banco de dados, escrevendo consultas SQL, gerenciando conexões manualmente e executando a aplicação em um servidor Tomcat.

Posteriormente o professor me orientou a utilizar o SpringBoot. Com essa mudança o desenvolvimento se tornou melhor, passando a utilizar tecnologias como Spring Web, Spring Data JPA, Lombok, Spring Boot DevTools e o banco de dados H2.

Durante o processo de desenvolvimento tentei aplicar conceitos que estou aprendendo em um curso da Udemy, sinceramente não ficou tudo certinho.

Durante o desenvolvimento, procurei aplicar alguns conceitos de Domain-Driven Design (DDD) que venho estudando em um curso da Udemy. Embora o projeto ainda não siga todos os princípios da abordagem, foi uma ótima oportunidade para praticar e entender melhor sua aplicação (ainda está meio abstrato em minha cabeça).

Apresentação do projeto

O projeto foi criado com o objetivo de auxiliar oficinas e lojas de bicicletas no gerenciamento de seus atendimentos, proporcionando maior organização e agilidade aos processos internos.

O Bike Fácil permite o cadastro de clientes, produtos, usuários e a emissão de Ordens de Serviço (OS), facilitando o controle das manutenções realizadas e das peças utilizadas em cada atendimento.
